# P67 — Iranian Pricebook Catalog

کاتالوگ نسخه‌های فهرست‌بهای ابنیه برای سال‌های 1402، 1403 و 1404 ایجاد شد.

منابع عمومی وب وجود نسخه‌های سال‌های 1402 تا 1404 را نشان می‌دهند. این فاز عمداً نرخ‌های عددی را تا زمان دریافت فایل‌های اصلی و قابل‌اعتبارسنجی وارد نمی‌کند؛ بنابراین هیچ نرخ ساختگی وارد موتور برآورد نمی‌شود.

پس از دریافت فایل PDF/Excel هر سال، ingestion باید ردیف‌ها را با کد، شرح، واحد، مبلغ، فصل، نسخه و hash فایل ثبت کند.
