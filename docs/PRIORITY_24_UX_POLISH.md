# Priority 24 — UX Polish

## هدف
یکپارچه‌سازی تجربه کاربری دسکتاپ Windows-first بدون تغییر در منطق مهندسی، محاسبات، BOQ، مالی یا قراردادهای داده.

## پیاده‌سازی
- ناوبری گروه‌بندی‌شده بر اساس جریان واقعی کار:
  - شروع
  - متره و برآورد
  - مدیریت پروژه
  - کنترل و ابزار
  - سیستم
- صفحه راهنمای داخلی با میانبرها و مسیر شروع سریع
- میانبرهای سراسری:
  - Ctrl+N — رفتن به ساخت پروژه
  - Ctrl+O — رفتن به پروژه‌ها
  - Ctrl+K — رفتن به جستجوی فهرست‌بها
  - F1 — راهنما
- وضعیت پروژه در نوار کناری و StatusBar به شکل یکسان نمایش داده می‌شود.
- حالت فعال ناوبری، focus state، disabled state و hover/pressed state یکدست شده‌اند.
- جدول‌ها، ورودی‌ها، اسکرول‌بارها و ToolTipها از یک زبان بصری مشترک استفاده می‌کنند.
- Primitiveهای UX در `core/ui/ux.py` مستقل از منطق مهندسی نگه داشته شده‌اند.

## اصل سازگاری
Priority 24 هیچ API محاسباتی یا قرارداد ذخیره‌سازی Priorityهای 1 تا 23 را تغییر نمی‌دهد؛ تغییرات صرفاً در shell و presentation desktop و تست‌های UX است.

## تست
`tests/test_priority_24_ux_polish.py` قراردادهای میانبر، گروه‌بندی ناوبری، وضعیت پروژه و استایل‌های دسترسی‌پذیر را regression-test می‌کند.
