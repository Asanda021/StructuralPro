## خطاهای واقعی اصلاح‌شده

۱. برآورد بدون قیمت finalizable=True بود. ساختار مقدارها همچنان معتبر می‌ماند، اما unpriced_item_numbers مانع نهایی‌سازی مالی می‌شود. قیمت صفرِ صریح با قیمت مفقود متفاوت است.
۲. «تأیید و ثبت» در صفحه نامزدهای نقشه فقط در حافظه نشست تغییر ایجاد می‌کرد. اکنون «بازبینی نامزدها» و پیام روشن استفاده از متره گرافیکی برای ثبت پروژه نشان داده می‌شود؛ ذخیره جدید یا موازی ساخته نشد.
۳. GGUF فقط با تطبیق هش آماده اعلام می‌شد. اکنون magic/version/حداقل header نیز بررسی می‌شود؛ این همچنان اثبات inference نیست و بارگذاری واقعی باید توسط موتور انجام شود.
۴. workflowهای انتشار و چهار ویرایش خودکار exe/installer می‌ساختند. اکنون فقط workflow_dispatch با build_approved=true می‌تواند این jobها را اجرا کند. آزمون‌های کد و Windows source smoke ادامه دارند. VERSION تغییر نکرد و نسخه جدید تولید نشد.
