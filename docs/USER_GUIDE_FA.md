# راهنمای کاربر StructuralPro

StructuralPro یک پلتفرم Windows-first برای متره، برآورد و مدیریت پروژه‌های AEC است.

قابلیت‌ها فقط زمانی فعال معرفی می‌شوند که با شواهد Release/Runtime تأیید شده باشند. دسترسی تجاری و دانلود نسخه مشتری به حساب و Entitlement معتبر وابسته است و در نبود مجوز، سیستم fail-closed عمل می‌کند.

قیمت، Release، قابلیت و وضعیت تجاری نباید بدون منبع واقعی یا runtime evidence نمایش داده شود.
