# راهنمای سریع StructuralPro
1. پروژه را ایجاد و مشخصات پروژه را وارد کنید.
2. نقشه را اضافه و مقیاس را کنترل کنید.
3. متره طولی، سطحی و تعدادی را ثبت کنید.
4. آیتم‌ها را به فهرست‌بها/BOQ متصل کنید.
5. برآورد، ضرایب و گزارش را تولید کنید.
6. Revisionها را ذخیره و اختلاف‌ها را بررسی کنید.
7. قبل از تغییرات مهم Backup بگیرید.
8. پیشنهاد AI صرفاً پیشنهاد است و تأیید کاربر لازم دارد.
