# P70 — Official Pricebook Sources

منابع رسمی سازمان برنامه و بودجه/سامانه نظام فنی و اجرایی برای فهرست‌بهای ابنیه ثبت شدند. برای ۱۴۰۴، منبع رسمی آرشیو SAMA و تاریخ ابلاغ ۱۴۰۳/۱۲/۲۹ ثبت شده است.

تا وقتی بایت فایل خام دریافت و SHA-256 آن ثبت نشود، نرخ‌ها به‌عنوان دیتای داخلی ادعا نمی‌شوند. پس از دریافت فایل، P68 ingestion تمام ردیف‌ها را وارد و به موتور برآورد متصل می‌کند.
